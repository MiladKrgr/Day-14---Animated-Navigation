## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک منوی ناوبری مدرن و جمع‌شونده (Expandable Navigation Bar) است که با هدف تمرین تکنیک‌های پیشرفته انیمیشن و ترنزیشن در CSS3 و مدیریت وضعیت باز/بسته با جاوااسکریپت پیاده‌سازی شده است. در این نوبار، کاربر با کلیک روی دکمه‌ی تاگل، باز شدن روان کادر منو را همراه با چرخش سه‌بعدی و نمایش زیبای آیتم‌های منو و همچنین چرخش جذاب خطوط آیکون ضربدر تجربه می‌کند.


---
---
---


## ویژگی ها  
<!-- Features : استاندارد -->

- مدیریت وضعیت منو با متد بهینه‌ی classList.toggle('active') در جاوااسکریپت
- تبدیل ابعاد منو از عرض فشرده (۸۰ پیکسل) به حالت کامل (۳۵۰ پیکسل) با انیمیشن نرم transition
- چرخش سه‌بعدی ۳۶۰ درجه و ظهور شفافیت (opacity) برای آیتم‌های منو در محور Y (transform: rotateY(360deg))
- تبدیل خطوط همبرگری به علامت ضربدر (Close Icon) با ترنزیشن چرخشی چشم‌نواز (rotate(-765deg) و rotate(765deg))
- طراحی چشم‌نواز با پس‌زمینه گرادیان دوطرفه و استایل مدرن شناور (Floating Navbar)

## Project Description 📌
<!-- Standard : Project Description  -->
This project is an expandable and interactive animated navigation bar designed to practice advanced CSS3 transitions, 3D transforms, and minimalist state toggling using Vanilla JavaScript. Clicking the toggle button triggers a fluid expansion of the container, an engaging 3D rotation of the navigation links, and a multi-spin cross transformation of the toggle lines.
---
---
---

## Features 🌏
<!-- Standard : features  -->
- State toggling managed via clean JavaScript classList.toggle('active')
- Smooth container expansion from a compact 80px circle-pill to a full 350px navigation bar
- Dynamic 3D Y-axis rotation and fade-in effect (rotateY(360deg) + opacity) for menu list items
- Multi-rotation animation for hamburger lines into an ‘X’ close icon (rotate(-765deg) / rotate(765deg))
- Modern visual styling with split linear-gradient backgrounds and floating card aesthetics
